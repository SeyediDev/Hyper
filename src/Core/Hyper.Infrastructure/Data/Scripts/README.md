# اسکریپت‌های دیتابیس

## SeedPointsDistributionData.sql

این اسکریپت برای افزودن داده‌های نمونه برای نمودار **توزیع امتیازات بر اساس نوع** استفاده می‌شود.

### نحوه استفاده:

1. **قبل از اجرا، مقادیر زیر را با مقادیر واقعی دیتابیس خود جایگزین کنید:**
   - `@TenantId`: شناسه اکوسیستم
   - `@CustomerTenantId`: شناسه مشتری
   - `@EventLogId`: شناسه لاگ رویداد

2. **اجرای اسکریپت:**
   - اسکریپت را در SQL Server Management Studio (SSMS) باز کنید
   - مقادیر متغیرها را تنظیم کنید
   - اسکریپت را اجرا کنید

### داده‌های اضافه شده:

این اسکریپت 5 نوع مختلف امتیاز و تراکنش‌های نمونه برای هر کدام اضافه می‌کند:

1. **XP باشگاه** (~10,000,000) - بزرگترین بخش
2. **امتیاز خرید** (~1,800,000)
3. **امتیاز معرفی دوست** (~800,000)
4. **امتیاز نظرسنجی** (~450,000)
5. **امتیاز ارزش طول‌عمر** (~1,200,000)

### نتیجه:

پس از اجرای اسکریپت، نمودار Pie "توزیع امتیازات بر اساس نوع" باید 5 بخش مختلف با رنگ‌های متفاوت نمایش دهد.

### نکات مهم:

- اسکریپت به صورت idempotent نوشته شده است (می‌توانید چند بار اجرا کنید بدون ایجاد duplicate)
- اگر Points با همین نام‌ها از قبل وجود داشته باشند، اسکریپت فقط تراکنش‌های جدید اضافه می‌کند
- برای تست، می‌توانید مقادیر Credit و Balance را تغییر دهید تا نمودار متفاوتی داشته باشید
