# معماری یکسان‌سازی اتصال‌های خارجی

اتصال خارجی با `ExternalIntegrationConnection` ثبت می‌شود. مقدار `Provider` نوع سامانه را مشخص می‌کند و credentialها در `CredentialsJson` با رمزنگاری در لایه زیرساخت نگهداری می‌شوند.

نگاشت کالا در `ExternalProductMappings` به‌ازای هر اتصال مستقل است؛ بنابراین یک کالای هایپریک می‌تواند هم‌زمان به کالای باسلام، دیجی‌کالا و ترب نگاشت شود. هر اجرا در `IntegrationSyncRuns` ثبت می‌شود و وضعیت، تعداد موفق و خطا قابل گزارش است.

آداپتر هر سامانه `IExternalIntegrationAdapter` را پیاده می‌کند. سرویس هماهنگ‌کننده فقط بر اساس `Provider` آداپتر را انتخاب می‌کند و هیچ وابستگی به API باسلام یا سامانه خاصی در دامنه ندارد.
